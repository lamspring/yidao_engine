## 〇、新定律（钉死，为之后一切改造的第一性原理）

> **全场无定额：一切内在衰变皆为"率 × 存量"，一切上限皆为负反馈而非硬顶。**

细分为四款：

1. **内在衰变定率**：自然逸散、腐坏、遗忘、荒芜——衰减量 = 率 × 当前存量。e 式衰减（指数），永不归零，只趋余烬。
2. **外力冲击定额**：雨蚀、风损、战斗搏耗、施工消耗——外部 forcing，与存量无关，保持定额。**此款是第一款的重要边界：定率化只改"内在衰变"，不改"外力损伤"。**
3. **资源上限负反馈**：种群、树木、传闻——增长自带刹车（logistic 或概率存活），全局硬顶仅作**安全阀**保留，设计上永不触发，触发即视为负反馈失灵的 bug。
4. **安全阀留痕**：安全阀（ANIMAL_MAX / TREE_MAX / POP_CAP / MAX_SPIRITS）每次触发记一条 `【越界·安全阀】` 事件。长跑中触发次数必须为 0——为 0 才证明负反馈真的接管了。

**理论依据**（作者已认可，录此备查）：
- 自然界的普遍规则是 dx/dt = kx（变化率与当前量成正比），e 是其在连续极限下的解；
- 指数分布是唯一"无记忆"的连续分布——与底座哲学"世界无史，只有此刻"互为定理：只有此刻的宇宙，其衰变被迫是指数的；
- 定额衰减的物体可从剩余量反推年龄（隐含历史）；指数衰减的物体永远"不知道自己几岁"——如真实的放射性原子。

**已有的正确范例（不要动，作为改法参照）**：

## 一、P0：衰变定率化（e 式衰变全场落地）

> 本期只动"内在衰变"，不动外力冲击，不动行为逻辑，不动数值手感的大方向。

### P0-A 物品腐坏定率化

- **位置**：`yidao_core/world.py:207-215`（`Item.腐一步`）
- **现状**：`self.阳 -= rate`（rate 为定额，如生鱼 0.09/念）。后果：腐坏是"定时死亡"——每条鱼都在可预测的时刻腐尽。
- **改法**：
  1. 模块加载时由既有两表推导腐率表：`ITEM_DECAY_RATE[类型] = ITEM_DECAY[类型] / ITEM_YANG[类型]`（如生鱼 0.09/30 = 0.003/念）；
  2. `腐一步` 改为：`耗 = self.阳 × 率 × 气温系数 × 藏; self.阳 -= 耗`；
  3. 腐尽判据由 `阳 <= 0` 改为 `阳 < 0.5`（**余烬判尽**——指数衰减永不到零，须设余烬阈值）。
- **预期涌现**：腐坏时间呈指数分布——有的鱼两日即臭，有的撑过五日；"最后一点永不烂完"的余烬感；腐坏之痛（制陶动机）的触发时刻变得不可预测。
- **验收**：物品阳场永不负值；60 日长跑中储物腐坏事件仍发生（不错失制陶动机链）；三域账实差 < 1e-9。

**落地实录（2026-09-01）**：
- **参数终值**：腐率表按"等效旧寿"校准——`率 = 旧定额 × ln(初阳/余烬阈0.5) / 初阳`。需求书直式（定额/初阳）实测使生鱼 21 日方烬（旧制 5 日），"两日即臭"的预期与"腐坏之痛"动机链俱断；校准后平均寿命与旧制齐平，腐坏时刻随寒暑/屋内/陶罐条件散开，余烬长明不归零（指数衰减的本来面貌）。
- **实测**：单元探针——生鱼 333 念腐尽（与旧制齐），半衰期签名 56 念余半（±3%）；四种子 60 日制陶领悟 13–17 起、陶罐烧成 12–15 只（动机链完好——储水之需通路本就主供）。
- **验收全过**：阳场非负；59 项断言全过；双跑逐字节一致；三域账实差 < 1e-9。

### P0-B 建筑/火堆/井/围栏/尸骸/径 逸散定率化

- **位置**：
  - `world.py:636` 茅屋 `HUT_DECAY`（0.030/念 定额）
  - `world.py:687` 火堆 `FIRE_DECAY`（0.06/念 定额）

  - `world.py:721` 井 `WELL_DECAY`（0.012/念 定额）

- **改法**：各常数除以对应初阳得衰率（如 HUT 0.030/80 ≈ 0.000375），改为 `耗 = 阳 × 率`；塌/熄/废判据统一设**余烬阈值**（建议：屋/井/栏 阳 < 0.5，尸骸 阳 < 0.5，火 阳 < 1.0——火星余烬最耐久）；径改为 `tread ×= (1 - 率)`。
- **边界（重要）**：雨蚀 `HUT_RAIN_DMG`、风损 `HUT_WIND_DMG`、积水 `HUT_FLOOD_DMG`、冻裂、雨淤井 `WELL_RAIN_SILT`、汲井损耗 `0.3`——**这些是外力冲击，保持定额不动**（定律第二款）。
- **预期涌现**：
  - 火：**大火烈烈速燃，星火余烬经久**——火堆越大烧得越快，将熄之火久久不明灭（物理上真实：燃烧速率∝燃料表面积）；
  - 屋：新屋挺拔经久，老屋衰朽加速感消失，改为"老屋长期残破将塌未塌"——**将塌未塌的危房是故事温床**；
  - 径：旧径荒芜先快后慢，残影长存——"荒废多年的故道隐约可辨"。
- **验收**：诸场非负；塌屋/火熄/井废事件在 60 日长跑中仍各发生 ≥1 起；账实差 < 1e-9。

**落地实录（2026-09-01）**：

- **实测**：四种子 60 日——塌屋 7–12 起（基线 16–27，**危房长存已验**：屋不再定时塌，将塌未塌者长期矗立）、火熄 1–7 起（基线 7–13，**余烬经久已验**）、井废 0 起（基线亦 0——井为石工，寿以百日计，60 日内不发生是旧制本貌，此条验收放宽并注明）。径之荒芜改乘性后旧径残影长存。
- **手感对照**（60 日 × 四种子，括号内基线）：存活 11/19/9/16（14/16/13/15），塌屋 12/10/12/7（16/13/27/16），传闻 778/839/807/493（905/514/427/666）。无变味。
- **验收**：61 项断言全过（塌屋/火熄仍发断言守护；井废放宽注明）；三域账实差 < 1e-9；双跑逐字节一致。

## 二、P1：上限负反馈化（硬顶退位为安全阀）
