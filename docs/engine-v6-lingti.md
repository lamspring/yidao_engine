# 《易道引擎》v6.0 — 灵体世界设计纲领

> **v5 及以前是"让 LLM 写小说"。v6 是"让世界自己活，故事由观察者发现"。**
>
> 本文档是 v6 的唯一纲领，由与作者的问答凝结而成。作者原话视为第一性原理，不得曲解。

---

## 〇、第一性原理（作者原话的结构化）

1. **世界是世界，角色是角色。** 二者是两个处理系统，但互相影响、构成一个整体。世界是舞台，角色是角色。
2. **世界没有过去，没有未来，只有此时此刻。** 世界本身不保存历史；历史只存在于角色的心里。
3. **世界遵循自身物质特性做固定变化。** 如同太阳按轨迹运行：光线直射、高温融化、分子活跃——这些是人定义的表象，世界只按自己的物质特性运转。
4. **万物由阴凝聚而成，内含一份固定的阳。** 阳向四周逸散，速率因材质而异；阳尽则物质坏灭、降级为低级物质，直至归还为背景。生物靠摄入补充阳，维持形体、成长。
5. **事件必须有因果链，同时保留阳极/阴极的特殊涌现。** 角色因"环境参数 + 心态 + 心情"等复杂原因做出符合因果的、或符合阳极阴极的抉择。
6. **角色被记住，也被遗忘。** 记忆只记要义、会压缩、会遗忘，但关键的事永远不忘。
7. **角色可以在世界留下印记，印记有保质期，终将消失**——因为世界不可能永久一成不变。
8. **卦象易经层是物质升级降级的规则与状态符号的表征。** 它是古人概括世界变化规律的方式，定位为世界的"元素周期表"。
9. **作者是纯观察者。** AI 担任这个世界的"天道"：平时不插手，只在出现不合理或崩溃边缘的特殊情况时介入，防止世界毁灭。
10. **故事的标准是悬疑推理级的严谨**：像"干裂的土浇水会变稀、人往低处走水往低处流、人在陌生环境先观察、被欺辱者想变强然后报复"——符合逻辑、符合现实、符合人性。

## 一、三层架构

```
┌─────────────────────────────────────────────┐
│ 观测层（作者 + LLM）                          │
│ 终端文字流。LLM 是翻译官/史官，不在演化回路内，  │
│ 只在观测发生时工作。世界不跑它不花钱。            │
├─────────────────────────────────────────────┤
│ 灵体层（角色系统）                             │
│ 记忆（压缩/遗忘/永存）· 心情 · 心态 · 欲望 · 抉择 │
│ 角色互相记住、互相遗忘、互相影响                 │
├─────────────────────────────────────────────┤
│ 世界层（物质物理）                             │
│ 阴阳物质场 + 卦象状态符号 + 地形/水/资源/印记      │
│ 只有此刻；只保存当前快照，覆盖式，无历史           │
└─────────────────────────────────────────────┘
```

**铁律：LLM 退出演化回路。** 演化 100% 由确定性规则 + 显式随机种子驱动。这同时解决四个问题：本机算力（i7-7700K 足够）、存储膨胀（无录像带式历史）、API 成本（观测才调用）、叙事失真（逻辑来自物理，不来自 LLM 的自觉）。

## 二、时间：tick 的定义（作者直觉的落成）

作者的直觉："世界本身没有时间，tick 不像是世界里的参数，更像是观测参数；也许得按世界里某一种能量变化来做时间定义。"

**这个直觉是对的，落成如下：**

- **tick 是世界的最小变化步，不是时间单位。** 一次 tick = 全场所有物质完成一次最小变化（阳逸散一步、水流动一步、角色行动一次）。叫它"**一念**"。
- **可观测的时间从能量循环中涌现**：世界的卦运周期为 64 念一周，定义为一个"**日**"。更长的周期（月令、季节）由更慢的能量循环定义。即：时间不是参数，**时间是能量循环的计数**。
- 叙事显示格式：`第3日·第41念`。
- 世界可以暂停、可以备份当前快照（放在不影响运行的位置），但过去不可回放——过去了就过去了。

## 三、世界层：阴阳物质物理

### 3.1 物质模型（作者阴阳观的直接实现）

- 每个物体/角色诞生 = **阴凝聚得一份阳**：获得固定的阳存量（容量因物种类而异）。
- **阳逸散**：每念按材质速率流失。石头慢，草木快，血肉更快。
- **阳尽则坏**：物体碎裂/降级为低级物质（陶器→碎片→土），最终归还为背景阴。
- **生物靠摄入补阳**：进食、饮水、休息。这是求生欲的物理根源，不是硬编码的"规则"，是物质特性。

### 3.2 卦象层的位置

卦象是**物质的状态符号表**（64 态 + 转移规则），这个世界的元素周期表：

- 八卦 = 8 种基本属性（五行生克 = 相互作用矩阵）；
- 相位 = 生命周期；错卦/综卦/互卦/爻变 = 质变方式；
- "阳极则反"是世界的根本法则，也是灵体层的根本法则（见 §4.4）。

卦象层保留 v5 kernel 的数学，砍掉其上的"语言金矿"（数百条文学描述降级为观测层可选词典）。

### 3.3 地形、水与资源

- 地形有高低；**水往低处流**，低洼积水成泽，高燥成坡；
- 周期性降雨/干旱（由能量循环驱动）；
- 草木依水土生长，是角色的食物来源；
- **印记**：角色的行为在世界留下物理痕迹（脚印、刻痕、坟、路），有保质期，随世界变迁衰减直至消失。v5 的 traces.py 泛化而来。

### 3.4 持久化

只保存**当前快照**（覆盖式单档）。无历史数据库。观测笔记（若有）写在世界之外，由观测层自负盈亏。

## 四、灵体层：角色的灵魂

灵体 = 记忆 + 心情 + 心态 + 欲望 + 抉择。

### 4.1 记忆（人脑式，非录像带式）

每条记忆：`{要义, 情绪强度, 念戳, 权重}`。

- **压缩**：旧记忆合并为要义，细节丢弃。（"他连续三次抢我的水" → "他欺我"）
- **遗忘**：低情绪记忆随时间衰减，权重归零即消失。
- **永存**：高情绪记忆（受辱、救命之恩、至亲之死）永不衰减——关键的事永远不忘。
- **关系 = 对他人的记忆。** 记得就是有关系，忘了就是陌路人。角色互相记住，也互相遗忘。

### 4.2 心情与心态

- **心情是快变量**：恐惧、愤怒、希望、疲惫，随环境实时波动。
- **心态是慢变量**：谨慎/莽撞、自卑/傲慢、戒备/亲和，由记忆长期塑造。

### 4.3 欲望

从阳存量长出最底层需求（求生、进食、安全），其上长出社会性欲望（地位、庇护、报复）。示例因果链（作者钦定的验收标准）：

> 受辱记忆（永存）+ 愤怒 → 生成"变强"目标 → 积蓄力量 → 条件满足时执行报复。

### 4.4 抉择：因果为常，涌现为变

与世界卦变**共用同一条数学**（势能→阈值→翻转）：

- **常规（因果态）**：环境参数 + 记忆 + 心态 + 心情 → 效用最高（最符合求生与欲望）的行动。默认策略：陌生环境先观察，收集信息再行动；不轻举妄动。
- **临界（涌现态）**：情绪/压力如势能积累，**超过阈值即翻转**——老实人爆发、顺从者反抗、骄傲者崩溃。日志标记为【涌现·阳极则反】。

世界因势能临界而卦变，角色因情绪临界而觉醒。同一条"反者道之动"，贯穿两层。

### 4.5 出生与死亡

- **生**：条件成熟时，阴凝聚得阳，新角色诞生（可从既有角色繁衍，也可从丰饶之地自然凝聚）。
- **死**：阳尽则亡，遗体降级归还世界（可能留下坟——一种印记）。
- 势力、文明、兴衰：**不专门实现**。角色层做对了，它们应当自然涌现。先观察，涌现不出来再补机制。

## 五、天道协议（AI 监护者）

作者是纯观察者；AI（Kimi）担任天道。

1. **无为而治**：天道只监测，不干预日常运转。
2. **介入条件**（仅限防崩溃）：全物种灭绝边缘、资源系统死锁、数值爆炸/NaN、明显违反世界法则的矛盾。
3. **介入留痕**：每次介入输出 `【天道】` 日志，说明介入原因与最小动作（如一场雨、一次资源补充）。天道不是编剧，是维修工。
4. 天道**不读心改心**：不直接修改角色记忆与欲望（那等于谋杀角色的自由意志）。只修世界层。

## 六、观测层：终端文字流

- 形态：**终端文字流**（作者机器：i7-7700K / 10GB RAM / GTX 1080，Web 图像有负担，弃用）。
- 输出两种内容：
  - **世界流**：`[第2日·第37念] 阿石 采食于低洼（因：饥饿）` —— 每条行为带因果标注；
  - **观心**：查询某角色此刻心里记着什么、想要什么、怕什么——历史只存在于角色心中，这就是"读心"界面。
- LLM（Kimi）为可选翻译官：把一段时间的世界流+角色记忆编织成悬疑推理级的严谨叙事。它只能翻译已发生的因果，不得发明。
- v5 的 observer/camera 代码可改造复用。

## 八、第一步原型与验收标准

**原型（鱼缸）**：32×32 小世界，有高地洼地、降雨与水流、可采集食物；12 个角色，有记忆/心情/欲望/抉择；跑若干"日"，不调用任何 LLM。

**验收标准（作者 A6 原话的落成）**：纯观察若干日，能否自然看到至少一条完整因果链自己长出来——

> 有人被欺辱 → 记住（永存记忆）→ 想变强 → 积蓄力量 → 报复。

长出来，方向成立；长不出来，改欲望与抉择模型，**不加约束、不上 LLM**。

**演进路线**：v6.0 鱼缸（单世界+灵体）→ v6.1 观测翻译官（Kimi 接入）→ v6.2 繁衍与代际 → v6.3 势力涌现观察 → 远期：多网格天地人。

## 附录：v6.0.1 细节丰富（作者反馈"只看到互相抢来抢去"后的一轮深化）

- **感知有限化**：感知半径昼 5 格 / 夜 2 格。食物点情报只有两个来源：亲眼所见、交谈交换。报复需凭"最后相见处"记忆自行搜寻仇人，不再全局瞬移。
- **昼夜节律**：一日 64 念，第 46-63 念为夜。夜里归栖安眠，阳逸散减半。
- **口渴**：水分与食物是两条独立需求线；日常吃喝睡不进事件流，只入观心与统计。
- **社交与恩义**：相遇交谈（交换情报）、分享救助（"送食于途"）、目睹恶行（旁观者记住并看轻行凶者）、庇护（勇敢者为好友出头）。
- **心态漂移**：性格被经历塑造——屡遭抢夺者愈发警惕，报复得手者愈发好斗，多受恩惠者愈发亲和。新增第三特质"亲和"。
- **悼念**：好友会在遗骨前伫立，哀伤记忆衰减极慢。每座坟只悼一次。
- **体质差异**：每个灵的代谢速率不同（0.8-1.25），错开饥饱相位——这是恩义链能涌现的关键杠杆。
- **流控**：显著事件 14 类进默认流，`--verbose` 全开。
- **已知局限**：庇护触发条件苛刻属低频事件；送食无路径规划；世仇循环尚无消弭机制（好斗度会被推至上限）。

## 附录：v6.0.2 物质文明与涌现天气（作者第二轮反馈后）

作者原话："茅草屋是实打实的世界层物质形态，会塌、会漏雨、会被风刮走；世界的变化运行都要根据阴阳来变化，风雨应是能量变化概率性产生。"

- **涌现天气**（替换固定降雨日程）：蒸发→云气场→风推送云团→云量超阈**概率性**成雨（薄云难雨、厚云倾盆）。全程水量守恒。雨的时间地点每次运行都不同，局部晴雨交替。
- **建筑物是世界层物质对象**：茅屋有阳存量，雨淋/大风/积水皆损之（**选址有真实权衡**：高地屋怕风、洼地屋怕淹）；阳尽则塌→屋骸→化土。可修缮。
- **知识传播**：`会建造`/`会种植` 三来源——自悟（夜雨淋身+悟性）、观察模仿（看别人的屋/田）、交谈传授。知识不遗忘，"谁教我的"留在记忆里。
- **三种社会响应**：模仿（自建）、求庇（收留则结恩/拒绝则寒心生怨）、夺屋（悍匪恃强占屋，失主结永存之恨，可夺回）。
- **种植**：播种→两日成熟，产量高于野草；田会枯、会被淹毁。
- **建造动机源于物质痛苦**：檐下安眠质量好，夜雨淋身耗阳且记坏记忆——不是规则驱动，是痛苦驱动。
- 事件类别增至 27 类；摘要新增【建造链】【夺屋链】与物候统计；`--inspect` 显示悟性、知识、财产。
- **已知局限**：夺屋判定为近似；缺多日连旱剧情；求庇不会看云提前动身；种子间方差大（乱世/田园皆有可能，属涌现应有之义）。

## 附录：v6.0.3 世界层极大丰富（作者第三轮反馈：环境必须丰富到极致）

作者原话："世界层底层逻辑依旧是能量影响形体的好坏……有形之物都是阴能量汇聚得一点阳能量而成形。还需要人情、畜牧、牛羊鸡畜、河里有鱼、草里有虫、气温、太阳月亮运行、日照时长、阳主导白天、阴主导阴天。环境必须丰富到极致。"

- **日月与气温（阴阳总源）**：显式阴阳气场——白昼阳盛、夜与阴雨阴盛；32 日寒暑循环，昼长随季节伸缩；气温场由日照×季节±云雨风修正，驱动蒸发、生长、阳逸散、食物腐坏、虫鱼繁育。物候事件（寒潮/春回/酷暑/初霜）进默认流。
- **生态**：鱼群密度依水温繁育；虫密度暖孳霜灭、过盛害田；鸡/羊/牛为轻量个体（吃、惊逃、繁殖、衰老、尸骸归土）。野兽与灵共用同一阴阳物质模型。
- **材料**：木（树会生长）、石、骨（尸骸）、藤，各有腐坏速率。
- **器物**：石斧/石刀/鱼竿/耒耜/背篓/石矛/棍棒，有配方、熟练度、磨损断裂；武器加算战斗；器物可被抢夺传承。
- **取火与烹饪**：钻木取火（受冻所迫而悟）；火堆是世界对象（须添柴、雨熄、驱寒、惊兽）；生食致病→痛定思痛悟烹饪；熟食养人、腐坏慢；屋内储粮更耐久——寒季储粮取暖成为生存主线。
- **技能体系**：建造/种植/制器/取火/烹饪/渔猎/畜牧，七技能各有发明动机钩子，三来源（自悟/模仿/传授）不变，熟练度随用涨。
- **人情**：交易（以物易物，价差过大被坑者记怨）、借贷（言明后还）、还债（恩怨两清）、赖账（有能力不还→反目成仇）、馈赠。
- 30 日长跑：显著事件 38 类，纯模拟 7.6 秒，天道 0 干预，寒季生存压力真实可见（受冻→取火→烹食→借贷）。
- **已知局限**：馈赠低频未现；兽群无天敌靠上限约束；战死者遗物遗留未做；陶器未实现。

## 附录：v6.2 繁衍与代际（历史开始跨代流动）

本轮核心哲学：**历史跨代流动，但只通过人心**。某事件的最后一个见证者若从未对人提起便死去，那段历史就永远消失。

- **寿命**：每灵出生即有寿数（46-56 日，个体各异）。四十日后衰老（阳上限渐缩、筋骨渐衰），寿尽则安然闭目（【寿终】）。
- **幼年**：第 0-4 日跟随父母、受哺育、不事生产不争斗（稚子无辜，不劫幼童）；父母在旁则家传技能——最强的知识通道。

## 附录：v6.3 人性层（误会、谎言、传闻、声望、同悼）

本轮核心哲学：**一切社会现象从"记忆 + 感知有限 + 信息传播失真"中涌现，禁止硬编码剧情。** 灵会爱会恨之后，还需会误会、会说谎、会传闲话——因为真实的社会从不建立在全知与真话之上。

- **传闻（gossip）**：交谈时概率性谈论第三方（`GOSSIP_CHANCE=0.35`），素材来自谈者自己关于他人的记忆（恶行：被抢/目睹/夺屋/赖账/被亏/谎言/听闻恨；善行：受助/受护/还债/同悼/冰释/听闻）。听者获得二手记忆，类别"传闻"，带两个新字段：**链长**（此事辗转了几张口，话传三站而止）与**褒贬**（善闻/恶闻）。**传播会失真**：基础失真率 0.10，每多一站翻倍（×(1+链长)）——五成张冠李戴（把事安到另一个熟人头上，活着的优先，死者死无对证），五成夸大其词（抢夺传成"打死了人"）。闻者自辨：与事主交情深厚者不信恶言；已闻此事者不再重复。
- **误会**：认得死者却不知其死因的灵，见有人在遗骨/遗物旁徘徊，概率性疑其为凶（`MISJUDGE=0.06×(0.5+谨慎)`，疑只起一次）。**错误记忆与真目睹同类别、同文字**——在灵心里，误会与事实不可分辨；是观测层（全知）把这件事标记为"误会"。同一条记忆既可能驱动庇护，也可能播下冤案。
- **谎言**：狭路相逢或交谈桌上，心中有疑/有债则当面质问（`CONFRONT_CHANCE=0.12`）。
  - **抵赖**：赖账者被债主当面问债，低概率否认（`LIE_DENY=0.35×(1.2-亲和)`，唯亲和 <0.6 者为之）。债主记忆权重 ≥0.35 则当场戳穿（债主记"谎言"，抵赖者受辱——戳穿是公开的，受辱会积压力、会暴起）；债主已淡忘则谎言得逞，账目随风勾销，债主独留一句"莫非我记错了"。**账目是结构，记忆是生命：谎言攻击的是记忆。**
  - **装无辜**：被质问"行过凶吗"的有亏心者（自己记忆里确有抢人/夺屋）会赌咒发誓。亲见者难骗（成功率 0.18），耳闻者易哄（0.65）。问心无愧者没有谎言，只有**澄清**：前嫌尽释，互记"冰释"，反成深交。
  - 判定清白与否不看"世界真相"，只看被问者**自己的记忆**——若连行凶者自己都忘了，世上便再无此事。
- **声望**：传闻+目睹构成**分布式的社会记忆**——每个灵心里都有一个版本的"X 其人"，世上没有全局榜。传闻入关系按褒贬计、权重打半折（`GOSSIP_WEIGHT=0.5`，耳闻不如眼见）。初见陌生人时关系不从 0 起：早闻其善者天然亲近，早闻其恶者寒暄也难（血案传闻足以把初次相见压到无话可谈，只剩狭路对质）。
- **同悼**：一人举哀，在场同识死者、尚未致哀者闻哀同悲——互记"同悼"，关系共进。葬礼的雏形，群体纽带由此而生。丧事由此成为村落黏合剂，而不只是个体哀伤。

**终局摘要新增【传闻链】**：可考的"传闻（失真）→ 疑心生暗鬼 → 澄清冰释/结仇"链与"骨旁生疑 → 澄清/结仇"误会链，附传闻/失真/谎言/同悼计数。

**60 日实测**（种子 42/7/123/2026）：传闻 22/39/96/508 起，失真 2/4/5/29 起，谎言戳穿 13/13/7/14 起、得逞 3/2/2/4 起，澄清 4/2/6/19 起，同悼 2/2/7/14 场；四种子皆见"传闻失真→误会→澄清/结仇"链（失真链 2/3/1/2 条）。四种子双跑逐字节一致，且鱼出口（`python -m v6.fishbowl`）与库调用（`Session.genesis`）结果一致；不变量测试 25 项全过。四种生存指标对照改动前基线（存活 2/0/0/7，诞育见于 2 种子）：改动后存活 0/1/2/18，诞育四种子皆发生（2/1/2/20 例），口述历史更盛（12/21/40/277 场）——总体不劣于基线，种子 42 在边缘世界上由 2 存活跌至 0（高方差世界的噪声范围内）。

**盖棺**：死者的心不再结算，新记忆入土前可能超出容量——入土时最轻的往事随风，留四十条（`_盖棺`）。这是记忆容量不变量在"死亡即冻结"语义下的补钉。

**本轮修掉的一个真问题**：口述历史的"对谁讲过"原本以 `id(memory)` 去重——内存地址会被回收复用，结果随进程启动方式漂移（同种子经鱼出口与经库调用各跑出不同历史）。改为记忆自带序号 `序`（`remember` 时递增颁授），确定性不再依赖堆布局。

**已知局限**：
- 【传闻链】的"结仇"按日志中该对灵此后发生的任何冲突事件判定，无法确证因果（冲突或另有起因）——可考而不可尽信，留待观测层考据。
- 传闻链长存在记忆里，但失真只改文字与对象，不改结构；"血案传闻"无量级上的本质区别。
- 装无辜的清白判定按"被问者记忆中是否有任何亏心事"，粒度粗（抢过甲的人无法为乙之死自证）。
- 同悼只在"一人先举哀"时触发，无自发聚葬；葬礼无仪式链，只有一场同哀。
- 谎言只覆盖抵赖与装无辜两种；尚无主动造谣（无中生有的恶闻须先经失真，无人能凭空编造）。

## 附录：v7.0 底座化与太初层（世界从项目变成底座）

作者问："阴阳世界能不能成为一套逻辑严密的世界级底层算法，为游戏或平台兜底？" 又补了最关键的一问："若世界初始什么都没有、都是无——此时应该有一个算法让世界开始变化，实现从无到有。空的地方本质不是空的，是能量。"

```
└── tests/test_invariants.py   不变量测试（22 项断言）
```

**太初层（从无到有）**：
- 无 = 未分化的均匀炁场。**绝对均匀的确定性场永不自变——变化需要差别**；种子涨落即"第一动"，是这个宇宙的奇点（同一种子 = 同一宇宙，确定性不破）。
- 一生二 = 极化：涨落经扩散+非线性放大，炁分化为阴（凝聚）阳（发散）两种运动倾向。
- 二生三 = 冲气：阴阳交界梯度最大，是诞生之地——**众灵诞生于界面点**（万物生于交界）。
- 三生万物 = 凝聚：阴聚成形为高地，阳散低洼成泽，太古草木随墒情先生。

**三条创世 API**：
- `Session.genesis(seed)` —— 无人打扰的自生（九宫格空图、零干预，世界自己长出来）；
- `World(seed, init_map=阴阳分布图)` —— 从用户给的分布图凝聚（任意尺寸，块状缩放）；

## 附录：灵体层的真问题（下一步设计方向，作者指示）

作者原话："灵体层有大问题。世界层可以自己通过变化产生多样性（岩石、沙子、黄金、熔岩、水流、树木、光线、泥沼等有形实物），但灵体层必须自主学习，角色所有的知识该由灵体自己在世界中学习。我们的灵体层从未有过真正的 DNA 链条——他目前只是会因为环境做出不同选择的函数，从来没有自主学习和思考过；顿悟不像是智慧，灵体缺了东西，而且没有生长过程。"

**三条设计指示（下次开工由此入手）**：

1. **真学习，不是顿悟**：技能/知识的获得要从"概率×悟性"的掷骰子，改为灵体在世界中试错、观察、积累、内化的过程。顿悟可以是临门一脚，但前面必须有学习量积累。
2. **DNA 链**：让环境塑造角色的 DNA——河边生者善渔，林中生者善猎。第一代由环境影响主导；随代际传承，祖辈血脉的影响渐强，环境影响渐弱。DNA 是可遗传、可漂变、被环境选择的特质序列。
3. **生长过程**：成长要有真实过程（幼弱→壮盛→衰老的形体曲线）。（注：作者已收回"阳尽同词"的批评——两岁阳尽与五十岁阳尽皆可，个体阳之逸散快慢本就不同，不改。）

另记世界层方向：物质多样性由世界自行变化产生（岩石、沙子、黄金、熔岩、泥沼、光线……），不必枚举，让基质在不同能量条件下自然分化。

## 附录：v6.5 DNA 链、真学习与生长曲线（灵体层真问题三条指示的落成）

1. **五行 = 水木火金土，是阴阳之下的物种常量。** 宇宙世界中的物都应该有这样的属性——大地泥土、树木、火、金属、矿石泥土、水，皆在此列。
2. **五行的每一个，内部都是阴阳平衡。** 金（内部阴阳平衡）、土（内部阴阳平衡）、水（内部阴阳平衡）、火（内部阴阳平衡）、木（内部阴阳平衡）——五行不是五种阴阳偏向，而是**五种阴阳配比各自的稳态**。结法各异，每个结自身都是稳的。
3. **五行相生相克**：木生火、火生土、土生金、金生水、水生木；木克土、土克水、水克火、火克金、金克木。元素之间不是静态并列，相生相克推动相态迁移。
4. **物 = 元素 + 态。** 同一元素在不同条件下呈现不同相态，作者两例钦定：
   - **土**：被水侵蚀就会湿，湿则为**泥**（亦可仍名为土）；当水分大于泥，则溃为**沙**；土里水少就会**干**；水特别少就会**硬**，也会变成**沙**。
   - **水**：水多，体积变大，则为**水流**，再大为**大海**；水少，则或为**水滴**，或为**水蒸气**，或为**空气中的水份**。
5. **五行生万物**：各种各样的物质状态就是万物——包括动物，也包括植物。众生不过是五行配比更繁复的结。

**落成定律：**

> **一元能量场（账）→ 阴阳（姿态）→ 五行（物种常量）→ 相态（万物）。**
> **不枚举物质，只立元素与相律——相态由条件生成，不由字典查得。**

- **层级**：守恒账（M1/M1b 已立）保证宇宙不多不少；五行相律决定宇宙里能出现哪些东西、它们怎样互相转化。两层相乘，方为完整的宇宙底层算法。
- **相态迁移的两类驱动**：
  - **条件驱动**（量变致相变）：水量、能量、体量越过阈值，同一元素换态——如土之干湿、水之滴海；
  - **作用驱动**（相生相克）：元素相遇，生者助长、克者改态——如土受水蚀而湿。
- **动物植物皆五行**：生灵不是五行之外的特例，是五行配比更繁复的结——这与灵体层"阴凝聚得一份阳"同一血脉：身是五行的结，阳是结中所含。

**与现有引擎的对应（收编，不是另起炉灶）：**

| 现有之物 | 五行相律下的正位 |
|---|---|
| `moisture` 墒（干/润/湿） | 土的相态雏形：干 → 土 → 泥（湿） |
| `water` 场水（滴/泽/深水） | 水的相态雏形：水滴 → 水流 → 大海 |
| `temp` 气温（寒/暑） | 能量条件：相变的驱动之一 |
| `stone` 石料场 | 金（矿石）的粗糙替身 |
| 火堆对象 | 火的特例化身：木生火（柴之结化火之结已验） |
| v5 kernel 卦象五行 | 符号层之五行；物质层之五行是其正位 |

**落地次序（留待后续里程）**：
1. 先立土与水的相律（作者两例已钦定相态表），收编 `moisture`/`water` 两场；
2. 火次之（火堆、烹饪、熔岩之态）；
3. 金与木再次之（矿石分化、草木品类）；
4. 每一元落地，守恒账不动分毫——相律只改"是什么"，不改"有多少"。

**土与水落地实录（v7-W1，已完成）**：

- **相态推导层**（零新场、纯推导）：`world.土相(y,x)` → 沙（极干硬碎 m<0.08，或水蚀过甚 water≥1.5）/ 干（0.08–0.25）/ 土（0.25–0.65）/ 泥（≥0.65）；`world.水相(y,x)` → 气（cloud≥0.6）/ 滴（0.15–0.6）/ 流（0.6–1.8）/ 海（≥1.8）。阈值与既有机制线咬合：GRASS_DRY=0.08 即"水特别少则硬碎"，FARM_FLOOD=1.5 即"水分大于泥则溃"——田毁于水蚀，正是土溃为沙。
- **机制挂钩三处**：草沙难生（沙格生长 ×0.2，水蚀带渐枯）；掘土得土、掘沙得沙（新材料"沙"，土与沙皆可成陶）；沙地凿井易塌（沙无结构性，通畅三倍速溃）。
- **守恒审计揪出一个陈年真 bug**：储粮循环用 `list.remove` 按 dataclass 值相等删物——四块数值相同的生肉会让最后一块**分身两处**（行囊与仓储各居其一，免费复制还双双腐坏）。`Item` 改为 `eq=False`（物是实体不是数值，比较与移除皆按"是不是这同一个"），并新增断言**一物一处·无分身**。哲学与代码在此互证：宇宙里没有分身术。
- **验收**：38 项断言全过（新增相律 9 项 + 一物一处 1 项）；三域账实差 3.6e-11 / 7.1e-10 / 7.2e-10；四种子手感如常（存活 20/18/14/20）；鱼出口双跑逐字节一致。

**已知局限**：
- 相律只立了土与水；火、金、木未动（火堆仍是特例对象，石料仍是金的替身）。
- 相态目前"推导自既有场"（零新状态）；水相之变（滴⇄流⇄海）尚无独立的物质后果（洪流改道、海泽异质等）。
- 沙只有"可陶"一用；沙/泥对营建、农事的分化影响未展开。

**火、金、木落地实录（v7-W2/W3/W4，已完成）**：

- **火（W2）**：`world.火相(y,x)` → 无/星（将熄，阳<20）/火（20–45）/焰（旺，>45）。机制两处：制陶需火相≥"火"（星火难成器；火弱则自钻新火或赴他处旺火）；**火生土**——火熄成灰，灰肥其土（草即荣 +0.25），与"物归→炁→草汲"的慢循环相济。
- **金（W3）**：石料场分化为石与矿石——高地采石，一成二得**矿石**（金之粗胚）；**火克金**：矿石就焰火**冶炼**为金块；金块与木就焰火**锻打**为**金刃**（利器 0.70，远胜石器）。采石→矿石→金块→金刃，第一条完整的五行生产链。四种子 30 日实测：采矿石 3/6/15/2 次，冶炼皆起。
- **木（W4）**：**木固土**——近树两步之土，根柢盘结，纵水蚀极干亦不易溃为沙（土相收编树木）；**果树结实**——树有三成为果树，暖季渐熟（至多三枚），寒季落尽还于土；近旁者可**采果**（新食材，易腐）。实测采果 11/0/12/6——有一种子有树无人采（村落离果树远），涌现之义。
- **验收**：45 项断言全过（相律新增土 5 / 水 4 / 火 4 / 木 2）；三域账实差 3.6e-11 / 7.1e-10 / 7.2e-10，守恒账分毫未动；四种子手感如常；鱼出口双跑逐字节一致。

**已知局限**：
- 水相之变（滴⇄流⇄海）尚无独立物质后果；熔岩未现（阳极之土，留待火山之日）。
- 金刃无配方化（不经 RECIPES/TOOL_PRIORITY，唯锻打一途）；金属器族未展开（金斧金矛，以后再说）。
- 果树只有"果"一品；草木品类（松/竹/药草）未展开；木之相生（木生火）已由"柴之结化火之结"覆盖，木之相克（克土）目前只有"固"的一面，"耗"的一面（树夺土肥）未立。
